Upload daily pre-sales report

Upload a CSV or Excel (.xlsx, .xls) report exported from your calling/CRM system. The dashboard calculates team, agent, date, and disposition summaries from the column names it can recognize.

Common column names supported: Date, Agent Name, Assigned Leads, Attempts, Connected Calls, Lead ID, Disposition, Qualified Leads. You can upload a CSV with your actual columns; if names differ, the report may need mapping adjustments.
Data handling: this first frontend version processes the CSV in your browser and keeps it only in this browser session. It does not upload report rows to Cloudflare D1, so other employees/admin devices will not see the imported data yet. Shared, persistent reporting requires a secure Worker endpoint and database storage.
